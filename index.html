Conectar Google Sheet

El panel lee directamente el archivo growth_squads_tracking_2026: la pestaña "Plan Anual" + las 12 pestañas mensuales (Ene...Dic), tal como está armado hoy. Solo necesita el ID de la planilla — los nombres de pestaña ya están fijos.
⚠ Este navegador no permite guardar nada (ni siquiera localStorage). Puede pasar en modo incógnito con almacenamiento bloqueado. Vas a poder usar el panel, pero tenés que volver a pegar la URL cada vez que recargues la página.
Recomendado si el CSV te da datos viejos: el endpoint de Google que lee el CSV a veces queda cacheado y no se actualiza. Un Apps Script lee la hoja en vivo, sin ese problema. Es no-destructivo: no modifica ni duplica el documento oficial, es solo una extensión.
1. En el Sheet: Extensiones → Apps Script
2. Borrá el código de ejemplo y pegá el que te dejé abajo (con tu Sheet ID)
3. Implementar → Nueva implementación → Aplicación web
4. "Ejecutar como": Yo · "Quién tiene acceso": Cualquier usuario
5. Copiá la URL que te da (termina en /exec) y pegala acá abajo
Paso previo en Google Sheets: Archivo → Compartir → Publicar en la web → "Todo el documento" → formato CSV → Publicar. El panel necesita leer cada pestaña (Plan Anual + Ene..Dic) como CSV público.
Sobre el horario de 20hs: este panel vive en tu navegador, no en un servidor. Se auto-actualiza al abrirlo y revisa cada minuto si ya pasaron las 20hs para sincronizar de nuevo, pero eso requiere la pestaña abierta. Para una sincronización 100% desatendida hace falta un Google Apps Script con trigger horario.
Cómo lee cada pestaña mensual:
Por cada squad busca el bloque "SQUAD · PO: ... · Own: ...", toma la fila de encabezado (Día | Fecha | producto 1 | producto 2 | ... | TOTAL) y las filas diarias hasta la fila TOTAL ACUM. El objetivo mensual lo toma siempre de Plan Anual (no de la fila "META MES" de cada mes, para evitar arrastrar desalineaciones si alguna celda quedó vacía ahí). El ritmo de cada producto se calcula prorrateando ese objetivo por los días con carga real.
